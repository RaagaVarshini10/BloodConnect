# 🩸 BloodConnect
A Blood Donor Management System built using **Java, JDBC, MySQL, HTML, CSS, Docker, and GitHub**.
## 📌 Overview
BloodConnect enables blood donors to register and allows patients to search for donors based on blood group and city.
## ✨ Features
- Register blood donors
- Search donors by blood group and city
- Store donor information in MySQL
- Responsive HTML/CSS user interface
- Dockerized backend and database
## 🛠️ Technologies Used
- Java
- JDBC
- MySQL
- HTML5
- CSS3
- Docker
- Git
- GitHub
## 📁 Project Structure
BloodConnect
│
├── backend/

└── README.md
## 🚀 How to Run
1. Clone the repository.
2. Start Docker Desktop.
3. Run:
```bash
docker compose up --build
```
4. Open the frontend in your browser.
5. Register a donor or search for existing donors.
